# Monte Carlo Lab

[Start the course](https://snowch.github.io/monte-carlo-lab/) · [Field notes](https://snowch.github.io/monte-carlo-lab/field-notes.html)

A comprehensive, hands-on Python course in modelling uncertainty and making defensible decisions. **60 bite-size core lessons, 16 optional advanced lessons and three optional workbooks.** The main examples span events, projects, inventory, measurement, reliability and mathematical estimation. Infrastructure is an optional application.

Every investigation has a prediction, editable Python, actual browser execution, an executed worked example, one change to try, a transfer question, two progressive hints, explanatory feedback and a stated limitation. Inputs identify invented or simulated provenance. A fixed seed is reproducibility, not validation.

Each of the 79 lessons and workbooks includes a captioned visual explanation. Formulas are typeset and Python snippets remain literal code. The first simulation plots its actual attendance draws; executed figures have phone and desktop versions with full-size links. Reference illustrations stay separate from your run.

## Use and develop

Basic Python is the only core prerequisite. The advanced route assumes the core, logarithms and elementary probability densities. Most initial passes take 6–11 minutes; exploration and an independent capstone take longer. Reading marks are self-reported progress, not assessed mastery.

```sh
npm ci
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m playwright install --with-deps chromium
npm run check
npm run dev
```

Open `http://localhost:5173/monte-carlo-lab/`. The Pages-shaped local path checks relative assets. GitHub Actions runs all checks before deploying `main` to GitHub Pages. Static output lives in `dist/`; it includes the locally served Pyodide runtime and hash-checked Python wheels.

- `src/course.json`: authored lessons, learning prompts and references.
- `python/`: standalone, independently executable examples.
- `scripts/execute.py`: generates worked output and SVG figures from exact published code.
- `scripts/visuals.py`: lesson-specific mathematical/reference illustrations with explicit targets and provenance.
- `scripts/figure_style.py`: responsive captures of the same executed plot data; logarithmic axes and original values are retained.
- `src/rich-text.mjs`: escaped formatting for `$LaTeX$` maths and backtick Python syntax.
- `scripts/layout.mjs`, `src/style.css`: readable interface, responsive routes and light/dark themes.
- `src/app.js`, `src/worker.js`: local drafts, editor, live Python, CSV and portable records.
- `tests/`: native statistical/reference checks, relative links and real browser/Wasm workflows.

## Records and privacy

No account, analytics or Python server. Code runs in a browser worker using pinned Pyodide 0.27.7, NumPy 2.0.2, SciPy 1.14.1, pandas 2.2.3 and Matplotlib 3.8.4. The substantial first-run download is self-hosted. Full offline use is not provided. Code, notes and reading marks use localStorage; the overview exports/imports them. CSV and completed runs remain in page memory until exported.

The core capstone has `inventory`, `project` and `measurement` starters. Set `case` in the code; optional CSV must contain a `value` column with at least eight positive, finite, nonconstant observations in the stated units. Structure checks do not validate provenance, independence or suitability. Run JSON preserves exact executed source, selected CSV, output, SVG figures and versions; Markdown report export attaches the completed execution to the learner’s reasoning.

## Design and evidence

The interface builds on the revised [Scientific Method Lab](https://github.com/snowch/scientific-method-lab), with larger readable typography and code/results in one flow. The bite-size learning structure draws on Assembly Lab and the worker/editor approach on Event Streaming Lab. Monte Carlo lessons and exercises are original; primary method references appear per lesson. See [learning design](docs/learning-design.md) and [review evidence](docs/review.md). Author review and automated execution do not establish learning effectiveness; a novice learner study has not been conducted.
