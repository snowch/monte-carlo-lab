# Concept audit: implementation record

Implemented 2026-11-14, following the [baseline review](concept-audit.md) of f9b0ce0 and the optional Lesson 0 added subsequently.

All **60 flagged items** (26 Gap, 8 Sequence, 26 Support, including the overview and field notes) have a concrete source remedy below. The other 21 baseline pages were checked for their dependencies; additional local notation support was added where useful. Optional Lesson 0 remains the preparation route. Course lesson identities and the 76-lesson progress denominator are preserved.

This is an author review of the repaired teaching route, not a claim of demonstrated novice comprehension. Source changes, mathematical checks and browser checks support different conclusions; automated execution alone cannot establish that an explanation teaches effectively.

## Design

- Essential definitions appear on the reading route with optional help closed. The three-paragraph lesson structure and one main outcome remain.
- Monte Carlo reference illustrations follow the explanatory paragraphs and any short local notation key.
- Lesson 2 executes its tiny array example. Lesson 4 uses ten explicit invented values. Lessons 28/30 use a scalar normal construction. Lesson 74 computes inspectable lag correlations rather than introducing FFT as a prerequisite.
- The original source boundaries, invented/simulated labels, conditional inference assumptions, complete experiments, hints and transfer questions remain.
- A saved code draft is retained when it differs from a newly published example. An unobtrusive note points to Tools for download/restore, avoiding silent loss of work.
- The homepage now has its own possible-events illustration, coordinated with the Scientific Method and SymPy homepages. This is conceptual artwork, not an execution record.
